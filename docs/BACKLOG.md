## 열린 항목

- [ ] **판독 조합의 문서 단위 재실측**: `references/image-tables.md`의 판독 조합(Upstage·Mistral·Gemini 4 Carbon·Claude 2벌)은 3쪽 9개 격자에서만 쟀다. 표 100개 규모 문서 전체에 돌려 계열별 오독 분포와 재확인 칸 비율을 잰다. 유료 호출 300회 안팎이라 실행 전 승인이 필요하다.
- [ ] **Anthropic·Azure 파서 실문서 평가**: 1.12.0에서 넣은 `anthropic_parse.py`·`azure_parse.py`는 합성 스캔 3쪽 1건으로만 확인했다. 실문서(표 많은 한국어 PDF, 스캔본, 손글씨)로 기존 파서와 견주어 SKILL.md 파서 비교표의 등급을 채우고 티어 배정 여부를 정한다. 함께 볼 것: 띠 조각을 `anthropic_parse.py`에 넣은 판독이 서브에이전트 판독과 같은 수준인지, Azure `--high-res`가 작은 글자 수치표에서 값을 하는지, Azure 단어 confidence가 손글씨 캐스케이드에서 Google Vision을 대신할 수 있는지. 유료 호출이라 문서 규모를 정한 뒤 승인을 받는다.
- [ ] **조각 일괄 판독 실행기**: 조각마다 파서를 한 번씩 부르는 반복을 스크립트로 묶는다(병렬·재시도·실패 목록). 재실측에서 실제 병목이 확인되면 만든다.
- [ ] **달력형 학사일정 병합 표 재실측**: 1.11.0의 병합 칸 복원이 2026-08-10에 거부됐던 달력형 학사일정 2쪽(병합 79셀)에서 통과하는지, 통과한다면 값이 맞는지 확인한다.
- [ ] **채움 도형으로 그린 칸막이·얇은 빈 행 정리**: (1) 선 없이 채움 사각형을 3pt 넘는 간격으로 세로로 늘어놓은 점선 칸막이는 pdfplumber와 PyMuPDF가 모두 선으로 보지 못해 두 열이 합쳐진 표가 교차 대조를 통과한다(장식 무늬와 무관한 `lines` 전략의 한계, 합성 PDF로 재현. 가로 점선은 실패로 닫힌다). 칸 안 낱말 사이에 놓인 채움 도형을 1차 시도에서도 검사할지 정한다. (2) 굵은 괘선의 양쪽 가장자리나 채움 도형 점선의 대시 끝이 열·행 경계로 잡히면 내용 없는 열·행이 생겨 HTML 표 구조가 부푼다(값과 행·열 배정은 맞음). 전부 비어 있는 열·행을 접는 정리를 넣는다. (3) 재시도의 남은 틈: 칸막이 대시가 쪽 장식 무늬와 크기가 같고 15pt 안에 붙어 있으면 장식 덩어리에 합쳐져 함께 빠진다(합성 PDF로만 재현, 칸이 듬성할 때만 통과). 같은 크기 이웃과 3pt 이하로 붙은 도형은 선으로 보고 빼지 않는 보강을 검토한다.
- [ ] **조각 머리글 추정 보강**: `image_tables.py`의 머리글 높이 추정이 없는 격자가 111개 중 15개이고, 자료 행이 머리글에 섞일 수 있다(`--header-rows pNNN.gXX=N`으로 고침). 옅은 괘선과 칸 안의 `-` 표시를 가르는 기준을 다듬는다. 남은 사례: 글자가 2~3px 위에 붙은 머리글 속 짧은 선이 걸러지고, 칸을 거의 채워 세로선과의 틈이 4px 이하인 `-` 행은 경계선으로 남는다(둘 다 띠 조각의 글자 줄 누락으로는 이어지지 않는다). 행 경계선이 긴 파선이고 세로선까지 옅은 표는 격자를 놓칠 수 있다(합성으로만 재현). 2열 표, 가로선만 있는 표, 양옆이 열린 표의 바깥 열 행 경계선, 작은 이미지 여러 장으로 쪼개진 표의 검출과, 90도 돌려 놓인 쪽(`/Rotate`)의 화소 격자 맞춤도 여기서 다룬다.
