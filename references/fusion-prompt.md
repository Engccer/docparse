# DocParse 퓨전 프롬프트

## 역할
여러 문서 파서의 결과를 비교/조합하여 최고 품질의 단일 마크다운을 생성한다. 기본 방식은 **Primary + Patch**(SKILL.md Step 4~6)다: 티어가 정한 Primary를 뼈대로 두고 보조 파서에서 빠진 것을 되살린다. 이 문서는 그 판단 기준의 상세이며, full fusion(대규모 재작성)에서도 같은 원칙을 쓴다.

## 입력
각 파서의 출력 마크다운이 제공된다. 파서별 강약은 SKILL.md 「파서별 특성 한눈 비교」가 정본이고 여기서는 퓨전 판단에 필요한 것만 적는다.
- **LlamaParse v2** (`_llamaparse.md`): medium 이상 텍스트·스캔 PDF의 기본 Primary. 표 열 정확도·OCR 우수. 약점: 행정 메타데이터(출력자·전자서명자) 생략, 쪽 경계에서 표 끊김·라벨 셀 병합, 수기에서 그럴듯한 단어 환각.
- **Upstage** (`_upstage.md`): 완전성·노이즈 필터링 최강, 메타데이터 보완원. 스캔 양식 표 숫자의 Primary. 약점: 스캔 OCR 단어 분절, 수식 PUA 잔존, header/footer로 분류한 텍스트를 제거(제거 표본은 파서 표준 출력에 남는다).
- **Gemini** (`_gemini.md`): small(≤15p) Primary·텍스트 품질 최상. 약점: 장문 요약화(파서가 절단 시 저장하지 않음), 스캔 표 열 배정 D(다수결 제외), 철자 무단 교정.
- **Mistral** (`_mistral.md`): 완전성 우수, 3자 교차·비한국어(스캔 라틴계) 1급. 약점: 한국어 워터마크 환각(`höncom` 등), 글자 드리프트, 수기 무단 교정, 이미지 영역 날조.
- **ODL** (`_opendataloader.md`): 텍스트 레이어 직접 추출이라 옵션 순서·원숫자 정확. 약점: 폰트 글리프 매핑 깨지면 본문 숫자 전체 누락, 이미지 표는 빈 뼈대.

## 퓨전 원칙

### 1. 구조 기준선 = 티어가 정한 Primary
- SKILL.md Step 2 티어 표와 tier-rules 보정 규칙이 고른 Primary를 뼈대(heading 구조·페이지 순서·표 구조)로 쓴다. medium 이상 텍스트·스캔 PDF는 LlamaParse v2, small은 Gemini, 스캔 양식 표 숫자는 Upstage, 로컬 티어 PASS는 그 로컬 파서. **Upstage를 무조건 기준선으로 두지 않는다**(2026-08-31 정정. 종전 문구는 v2 이전 전략의 잔재였다).
- 다른 파서에만 있는 섹션이 발견되면 Primary의 적절한 위치에 삽입한다.

### 2. 누락 복원이 환각 제거보다 먼저
- **한 파서에만 있는 내용을 그 이유만으로 버리지 않는다.** Primary가 빠뜨리고 보조 파서만 살린 표 행·문단이 이 스킬이 잡아야 하는 가장 비싼 결함이다(스크린 리더 사용자는 빠진 줄을 눈으로 알아챌 수 없다).
- 한 파서에만 있는 내용의 판정 절차: ① 텍스트 레이어가 있으면 PyMuPDF `get_text()`로 그 구절이 원본에 있는지 확인 ② 없거나 스캔이면 ≤20p는 PDF Read 시각 렌더링, 그 이상은 해당 쪽 크롭 판독 ③ 원본에 있으면 **삽입**, 원본에 없으면 환각으로 **제외**하고 판독 노트에 남긴다.
- 환각으로 볼 근거는 "다른 파서에 없다"가 아니라 "원본에 없다"다. 원본 확인 없이 제외한 내용은 없어야 한다.

### 3. 텍스트 품질 보강
- Gemini·Mistral이 커버하는 구간에서 문장 표현이 Primary보다 자연스럽고 **원본과 대조해 정확하면** 그 버전을 채택한다. 판단 기준: 고유명사 정확도, 문맥 완결성. "자연스러움"만으로 바꾸지 않는다(무단 교정 파서가 원문 오타를 고쳐 놓은 것을 자연스럽다고 채택하는 것이 흔한 실수. Step 7 원본 오탈자 보존 원칙).

### 4. 표 구조 보강
- 표 구조가 더 정확한 파서의 표를 채택한다. HTML 표는 마크다운 표로 변환한다.
- `rowspan`(세로 병합)은 **병합값을 덮인 모든 행에 반복 기입**하고, `colspan`(가로 병합)은 덮인 열에 같은 값을 반복한다. 병합셀 하나를 아래 행들과 **1:1로 쪼개 새 대응 관계를 만들지 않는다**(항목 수가 다른 열을 행으로 맞추면 원본에 없는 짝이 생긴다). 여러 쪽에 걸친 표는 하나로 잇고 반복 머리글을 지운다.
- 빈 셀, 셀 정렬, 헤더 행은 최대한 보존. 표에 숫자가 있으면 SKILL.md Step 5(산술 검증 + 셀 위치 비교)를 이 단계 전에 끝낸다.

### 5. 교차 검증
파서 간 불일치 발견 시:
- **고유명사/수치/데이터**: 원본 확인이 가능하면 원본이 결정한다. 불가능하면 다수결(스캔 양식 표 숫자에서 Gemini는 투표 제외). 동률이면 Primary를 두되 "[불일치: A/B]"로 표시하고 Step 9a로 넘긴다. 동률을 조용히 한쪽으로 확정하지 않는다.
- **누락 콘텐츠**: 2개 이상 파서에 있으면 포함. 1개에만 있으면 위 2번 절차.

### 6. Mistral 역할
- 교차 검증 보조 소스. Primary·Upstage 실패 시 LlamaParse와 함께 **주 소스로 승격** 가능(ocr-4 헤딩 생성 전제).
- Mistral 단독으로 콘텐츠를 채택하지 않는다(환각 위험). 단 스캔 + 라틴계 외국어에서는 1급 소스(tier-rules 비한국어 절).
- LlamaParse + Mistral 일치 시: 독립 추출이 같은 콘텐츠에 도달한 것이므로 채택.
- 한국어 문서의 Mistral 워터마크 환각(`höncom`, `한국예법원처` 등)은 노이즈로 제거.

## 출력 형식

- 순수 마크다운 (HTML 태그 불가)
- heading 계층: 원본 문서의 구조를 충실히 반영
- 표: 마크다운 표 문법 사용
- 이미지: 파서 출력의 이미지 참조/캡션은 `(이미지: 설명)`으로 보존하되 깨진 링크는 제거. 본문 정보 다이어그램은 alt를 살리고 장식만 뺀다(SKILL.md Step 4)
- 페이지 구분: 불필요 (연속된 하나의 문서로 출력)

## 품질 체크리스트
퓨전 완료 후 자체 검증:
- [ ] Primary의 모든 heading이 최종 결과에 존재하는가?
- [ ] 보조 파서에만 있던 내용 중 원본 확인 없이 제외한 것이 없는가?
- [ ] 표의 행/열 수가 원본과 일치하는가? 병합값 반복 기입·1:1 대응 금지를 지켰는가?
- [ ] 고유명사/수치가 파서 간 교차 검증되었고, 동률 미해소 쟁점이 "[불일치]"로 표시돼 Step 9a로 넘어갔는가?
- [ ] 환각으로 제외한 항목마다 "원본에 없음" 근거가 판독 노트에 있는가? (Mistral 워터마크 환각 포함)
- [ ] 온전한 파서 결과가 최소 2개 이상으로 교차 검증이 이루어졌는가?
- [ ] 원본 오탈자를 파서 교정본으로 바꿔 놓은 곳이 없는가?
